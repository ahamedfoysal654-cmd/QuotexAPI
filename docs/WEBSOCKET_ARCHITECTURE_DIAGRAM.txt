Message Flow Examples:

1. REQUEST/RESPONSE (with correlation):

   Client                                              Server
     │                                                    │
     ├─ send_request("login", {...})                     │
     │  request_id: "abc-123"                            │
     │  ────────────────────────────────────────────────►│
     │                                                    │
     │◄─────────────────────────────────────────────────┤
     │  {"msg": "auth_response",                         │
     │   "request_id": "abc-123",  ◄── Matched!         │
     │   "success": true, "ssid": "..."}                 │
     │                                                    │
     └─ Future resolved with response                    │


2. EVENT SUBSCRIPTION (server push):

   Client                                              Server
     │                                                    │
     │  subscribe("trade_result", handler)               │
     │                                                    │
     │◄─────────────────────────────────────────────────┤
     │  {"msg": "trade_result",          ◄── Event!     │
     │   "order_id": "...",                              │
     │   "result": "win", "profit": 85}                  │
     │                                                    │
     └─ handler(data) called automatically               │

Key Features:

✅ Single WebSocket Connection
   └─ All operations share one persistent connection

✅ Request/Response Correlation  
   └─ Unique request_id matches requests to responses

✅ Event Subscription
   └─ Services subscribe to message types they care about

✅ Message Routing
   └─ Automatic dispatch to correct handlers

✅ Real-time Streams
   └─ Server pushes updates (no polling!)

✅ Auto-Reconnect
   └─ Handles disconnections transparently

✅ Type-Safe Protocol
   └─ All messages defined in ws_protocol.py

✅ Async/Await
   └─ Modern Python async throughout
