DATA FLOW EXAMPLE - Placing a Trade:
════════════════════════════════════

1. User Code:          api.buy("EURUSD", 10, CALL, 300)
                                    ↓
2. Client (Facade):    Validates params, creates TradeRequest
                                    ↓
3. TradingService:     Validates business rules, checks balance
                                    ↓
4. HTTP/WebSocket:     Sends trade request to Quotex API
                                    ↓
5. Quotex Platform:    Processes trade, returns order ID
                                    ↓
6. DataService:        Tracks trade, monitors for result
                                    ↓
7. User Code:          Receives Trade object with result

KEY DESIGN PRINCIPLES:
═════════════════════

• Separation of Concerns:  Each layer has specific responsibility
• Dependency Injection:    Services receive config/dependencies
• Type Safety:             Pydantic models validate all data
• Async/Await:             Non-blocking operations throughout
• Error Handling:          Custom exceptions with clear messages
• Extensibility:           Easy to add new services/endpoints
• Testability:             Clear boundaries, easy to mock
